# AGENTS.md

This project keeps its agent/AI onboarding guidance in a single canonical file:

👉 **[`CLAUDE.md`](./CLAUDE.md)**

It covers the project's purpose, the JS-bridge-over-three-native-platforms
architecture (iOS / Android / Windows), the repository map, common commands,
build & publish flow, coding conventions, the RN version-compatibility matrix,
and the gotchas to watch for when contributing.

Read `CLAUDE.md` first. This file exists so tools that look for `AGENTS.md`
(e.g. Cursor, Codex) find the same guidance without duplicating it.
